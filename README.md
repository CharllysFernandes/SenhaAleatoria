# Senha Aleatória

Este projeto é uma ferramenta para gerar senhas aleatórias seguras. Dividir a senha em blocos facilita a visualização das senhas e a memorização.

## Para que serve

A ferramenta serve para criar senhas fortes e seguras, que são difíceis de serem descobertas por terceiros.

## Como usar

1. Acesse a ferramenta através do link abaixo:
   http://charllysfernandes.github.io/SenhaAleatoria/
2. Gere uma senha aleatória.
3. Divida a senha em blocos para facilitar a visualização e memorização.
4. Lembre-se de que a senha é salva na memória do navegador e deve ser apagada após o uso para garantir a segurança.
